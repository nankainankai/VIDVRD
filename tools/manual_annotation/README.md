# Manual Annotation Tools

These tools are retained for Gold data construction and manual audits. They are not part of the full-auto OpenClaw runtime.

## Contents

- `anno_platform.py`: manual relation annotation GUI.
- `process_frame.py`: one-off frame rename helper kept for reproducibility.
- `trajectory_completion/`: manual trajectory completion and interpolation tools.

Generated or copied sample labels live under `data/manual_samples/`.
